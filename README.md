## Выполненные шаги:

### 1. Установка Git
- Скачан установщик с официального сайта https://git-scm.com/downloads
- Установлен Git версии 2.55.0.windows.5

### 2. Настройка Git
- Настроено имя пользователя: `git config --global user.name`
- Настроен email: `git config --global user.email`

### 3. Генерация SSH-ключа
- Сгенерирован SSH-ключ командой: `ssh-keygen -t rsa -b 4096`
- Открытый ключ добавлен в настройки GitHub

### 4. Создание репозитория на GitHub
- Создан публичный репозиторий `test_Uliana`
- Добавлен файл README.md при создании

### 5. Клонирование репозитория
- Склонирован репозиторий локально: `git clone https://github.com/VedmaUliana/test_Uliana.git`

### 6. Внесение изменений
- Отредактирован файл README.md
- Добавлена информация о лабораторной работе

### 7. Отправка изменений
- Добавлены изменения в индекс: `git add README.md`
- Создан коммит: `git commit -m "Обновление README.md"`
- Отправлены изменения на GitHub: `git push`
